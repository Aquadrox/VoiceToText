            Snippets

            Dicter seulement le déclencheur insère le texte tel quel, sans LLM. Casse, accents et ponctuation ne comptent pas.

            Styles par application

            D'après la fenêtre active au début de la dictée : consignes ajoutées au nettoyage, ou texte brut. Le premier style qui correspond s'applique (ordre de la liste).

            Prompts

            Consignes données au LLM. Le prompt intégré convient dans la plupart des cas ; un prompt personnalisé permet d'adapter le résultat (plus concis, sans listes, autre registre) ou de simplifier les consignes pour un petit modèle local. Le dictionnaire et les consignes de style sont ajoutés automatiquement à la fin. Le prompt actif fait partie du profil LLM.

            Pendant la dictée

            Mode traduction

            Raccourci ci-dessus (Alt+Maj+T) ou menu de l'icône → Mode traduction : les dictées suivantes sont nettoyées puis traduites par le LLM. La pastille affiche la langue pendant la dictée. Le mode reste actif jusqu'à ce que vous le coupiez.

            Démarrage

            Exporter / importer les réglages

            Configuration, prompts, profils, dictionnaire, snippets et styles dans un fichier .toml : pour un autre PC ou une sauvegarde. Les clés API ne sont jamais exportées : à saisir de nouveau après l'import. L'import remplace tous les réglages (les actuels sont gardés dans config.avant-import.toml) et s'applique sans redémarrer.

            Nettoyage du texte

            Le texte transcrit est envoyé au modèle choisi pour retirer les hésitations et corriger la ponctuation. L'audio, lui, ne quitte jamais votre PC.
