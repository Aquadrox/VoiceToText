                Snippets

                Dicter seulement le déclencheur insère le texte tel quel, sans LLM. Casse, accents et ponctuation ne comptent pas.

                Styles par application

                D'après la fenêtre active au début de la dictée : consignes ajoutées au nettoyage, ou texte brut. Le premier style qui correspond s'applique (ordre de la liste).

                Prompts

                Consignes données au LLM. Le prompt intégré convient dans la plupart des cas ; un prompt personnalisé permet d'adapter le résultat (plus concis, sans listes, autre registre) ou de simplifier les consignes pour un petit modèle local. Le dictionnaire et les consignes de style sont ajoutés automatiquement à la fin. Le prompt actif fait partie du profil LLM.

                Pendant la dictée

                Mode traduction

                Raccourci ou menu de l'icône → Mode traduction : les dictées suivantes sont nettoyées puis traduites par le LLM, jusqu'à ce que vous coupiez le mode.

                Nettoyage par LLM

                Le texte transcrit (jamais l'audio) est envoyé au modèle choisi pour retirer les hésitations et corriger la ponctuation. Consignes : page Prompts.

                Profils

                Choisir un profil remplit le formulaire ci-dessous ; « Appliquer » l'active.

                Fournisseur

                Clé API

                Une clé par adresse, enregistrée tout de suite dans le Gestionnaire d'identifiants Windows : jamais en clair sur le disque, jamais envoyée en HTTP hors de ce PC. « Tester ces réglages » utilise la clé saisie ici si elle est remplie.

                Secours

                Essayé si ce fournisseur échoue (panne, délai dépassé, clé refusée), avant de coller le texte brut. Ex. un Ollama du réseau local en secours de DeepSeek.

                Tarif par million de jetons

                Paramètres supplémentaires (avancé)

                Objet JSON ajouté à chaque requête, propre au fournisseur. Exemple : {"thinking": {"type": "disabled"}} désactive la réflexion (lente) de DeepSeek et GLM.
